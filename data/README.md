# Data directory

The SQLite demo and astronaut health pages still use generated, clearly labeled synthetic records. A small genuine NASA OSDR RadLab ISS instrument-telemetry sample is included under `nasa/radiation/`; it is environmental detector data and is not linked to a crew member.

See `nasa/README.md` for the folder map and [the NASA catalog](../docs/NASA_DATA_CATALOG.md) for source status. Keep original responses immutable in `raw/`, processed tables in `processed/`, validation notes in `validated/`, and source manifests in `metadata/`.
